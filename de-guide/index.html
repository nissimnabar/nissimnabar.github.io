The Data Engineering Map

Data is produced in one place and needed in another. Data engineering is the discipline of moving it reliably, on time, in the right shape, and at a cost the business accepts. This guide works through that discipline one stage at a time. Each section has a core idea, a summary in my own words, and questions that test whether the idea can be applied.

The lifecycle this guide follows

Five stages carry data from where it is created to where it is used. Six undercurrents run beneath every stage.

  1. Generationsource systems
  2. Storagewhere data lives
  3. Ingestionbatch or stream
  4. Transformationraw to trusted
  5. Servinganalytics, ML, apps
Undercurrents: security · data management · DataOps · data architecture · orchestration · software engineering
